# 用户端 DEMO 制作指南 — 他俩能成

> 面向 DEMO 页面制作者（UI/UE）。本文档从用户操作流程的角度，说明需要搭建哪些页面、每个页面展示什么内容、用户如何完成完整的浏览→选择→下单流程。
>
> 本指南配合 `docs/frontend-miniapp-guide.md` 使用——前端开发指南提供数据结构和技术细节，本指南提供用户视角的流程和 UE 说明。

## 2. 底部导航

所有页面的底部固定导航栏，包含 5 个 Tab：

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 🏠 首页  │ 🎉 活动  │ 🎫 门票  │ 📦 商品  │ 👤 我的  │
│          │          │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

| Tab | 图标建议 | 标签 | 跳转页面 | 当前页高亮规则 |
|-----|---------|------|---------|------|
| 首页 | 🏠 / home | 首页 | 首页 | 首页 |
| 活动 | 🎉 / event | 活动 | 活动列表页 | 活动列表页 / 活动详情页 / 活动订单确认页 |
| 门票 | 🎫 / ticket | 门票 | 门票列表页 | 门票列表页 / 门票详情页 / 门票订单确认页 |
| 商品 | 📦 / goods | 商品 | 商品列表页 | 商品列表页 / 商品详情页 / 商品订单确认页 |
| 我的 | 👤 / user | 我的 | 我的（个人中心） | 我的页 / 订单详情页 / 订单成功页 |

**设计理念**：
- 活动和门票都是**直接报名/购买**，用户选择规格后立即进入订单确认，不需要购物车
- 商品也可采用直接购买模式（与活动和门票一致），同样不需要购物车
- 通过底部 Tab 直接切换业务类型，用户心智模型清晰：我要参加活动就点"活动"，我要买票就点"门票"

**行为规则**：
- 底部导航始终可见（除全屏查看图片等极端场景），当前所在页对应 Tab 高亮
- 高亮规则按层级：列表/详情/确认都属于各自业务 Tab 的高亮范围
- 从首页点击推荐卡片进入详情页时，对应业务的底部 Tab 需同步高亮

## 3. 首页

### 3.1 页面结构（从上到下）

```
┌─────────────────────────────────┐
│ 顶部导航 / 标题                  │
├─────────────────────────────────┤
│ Banner 轮播区（3 张）            │
├─────────────────────────────────┤
│ 三个入口卡片：活动 | 门票 | 商品  │
├─────────────────────────────────┤
│ 热门推荐列表（混合展示）          │
├─────────────────────────────────┤
│ 底部导航                         │
└─────────────────────────────────┘
```

### 3.2 Banner 内容

| 序号 | 图片 | 跳转 |
|:---:|------|------|
| 1 | 汽车生活节封面 | 活动详情页 |
| 2 | 什刹海摇橹船票封面 | 门票详情页 |
| 3 | 冰箱贴产品图 | 商品详情页 |

### 3.3 入口卡片

三个卡片并排（或轮播），每个显示：
- 图标/缩略图
- 分类名称（活动 / 门票 / 商品）
- 简介文案
- 点击进入对应列表页

### 3.4 推荐列表

混合展示 3 条数据（每种类型各 1 条），每项显示：
- 封面图（缩略图）
- 标题
- 价格区间（如 ¥99 - ¥199）
- 类型标签（活动 / 门票 / 商品）

## 6. 用户操作流程

### 6.1 活动：浏览 → 报名

```
首页 → 点击"活动"入口/推荐卡片
  → 活动列表页（浏览，选择汽车生活节）
    → 活动详情页（查看介绍、活动时间地点）
      → 选择票种（单人票/双人票/家庭票）
        → 点击"立即报名"
          → 订单确认页 ──────────────────────────────────┐
            │ 1. 确认票种和价格                           │
            │ 2. 填写报名信息（姓名+手机号+身份证号+性别）   │ ← 来自信息模板
            │ 3. 阅读并同意报名协议（如有）                 │
            │ 4. 查看退款说明（阶梯退规则）                 │
            │ 5. 点击"提交订单"                            │
            └─────────────────────────────────────────────→ 订单成功页
```

### 6.2 门票：浏览 → 购买

```
首页 → 点击"门票"入口
  → 门票列表页 → 选择什刹海摇橹船票
    → 门票详情页
      → 选择船票类型（普通/1039专属）
        → 点击"立即购买"
          → 订单确认页 ──────────────────────────────────┐
            │ 1. 确认类型和价格                           │
            │ 2. 点击"提交订单"                            │
            │ （摇橹船票无信息模板，或仅通过后端读取）      │
            └─────────────────────────────────────────────→ 订单成功页
```

### 6.3 商品：浏览 → 购买

```
首页 → 点击"商品"入口
  → 商品列表页 → 选择冰箱贴
    → 商品详情页
      → 选择款式（经典圆形/方型复古/限量金色）
        → 点击"立即购买"
          → 订单确认页 ──────────────────────────────────┐
            │ 1. 确认款式、价格、库存                      │
            │ 2. 填写购买信息（姓名+手机号+地址）            │ ← 来自信息模板
            │ 3. 点击"提交订单"                            │
            └─────────────────────────────────────────────→ 订单成功页
```

```
├─────────────────────────────────┤
│ [提交订单] 按钮                   │
└─────────────────────────────────┘
```

### 信息模板说明

不同类型需要填写的字段不同：

| 类型 | 模板名称 | 字段 |
|------|---------|------|
| 活动 | 报名信息 | 姓名、手机号、身份证号、性别（可选） |
| 门票 | 购票信息 | 用户可自己在后台配置（摇橹船票当前无模板） |
| 商品 | 购买信息 | 用户可自己在后台配置（冰箱贴当前无模板） |

> **DEMO 建议**：活动页按上方示例展示完整的报名表单；门票和商品页可展示一个简单的联系人信息表单（姓名+手机号），或者不展示信息填写区直接进入下单。

### 字段校验规则

| 字段 | 规则 |
|------|------|
| 姓名 | 必填 |
| 手机号 | 必填，11 位数字 |
| 身份证号 | 必填（如果配置了），18 位 |
| 性别 | 选填，单选 |

## 9. 导航结构

### 9.1 页面间跳转关系

```
首页
├── 活动列表 → 活动详情 → 订单确认 → 订单成功
├── 门票列表 → 门票详情 → 订单确认 → 订单成功
└── 商品列表 → 商品详情 → 订单确认 → 订单成功
```

### 9.2 每页必须的全局元素

- **返回按钮**：所有子页面（列表/详情/确认/成功）左上角
- **页面标题**：居中显示
- **首页入口**：从详情/成功页可返回首页

## 13. DEMO 搭建顺序建议

| 步骤 | 内容 | 产出 |
|:---:|------|------|
| 1 | 首页（Banner + 入口 + 推荐列表） | `index.html` |
| 2 | 活动列表页 | `events.html` |
| 3 | 活动详情页 + 订单确认 + 订单成功 | `event-detail.html` |
| 4 | 门票列表页 | `tickets.html` |
| 5 | 门票详情页 + 订单确认 + 订单成功 | `ticket-detail.html` |
| 6 | 商品列表页 | `products.html` |
| 7 | 商品详情页 + 订单确认 + 订单成功 | `product-detail.html` |
| 8 | 补充页面间跳转链接 | 全局 |

> 建议先做一个活动的完整流程（首页→列表→详情→下单→成功），跑通后再复制模板填充门票和商品的数据。
