# 现场管理弹窗「心动排名」TAB 设计

日期：2026-11-14
状态：已确认（用户确认：刷新按钮放右侧，其余按方案执行）

## 意图

现场管理弹窗（`OnsiteManageModal`）末尾新增「心动排名」TAB：展示现场活动心动配对的排名列表，
左右为男女生信息卡片、中间为互相心动情况，供管理员在活动现场快速查看心动数据。

## 目标 / 非目标

- 目标：新增 TAB + 列表展示 + 刷新按钮；点击卡片打开标准用户资料卡片。
- 非目标：不做实时轮询（手动刷新）；不动大屏页面；不改接口。

## 约束

- 接口用现成的 `activityApi.getOnsiteLovesCouples`（有现场心动的配对，按心动次数倒序，size 最大 100，循环分页拉全量）。
- 版式参考历史大屏心动排名（commit `a242ad5` 改版前的列表式）：**左男右女**（2026-11-15 用户调整，原左女右男），中间两行心形——上方红心=女方发起（`female_loves_count`）、下方蓝心=男方发起（`male_loves_count`）；不显示发起方文字与「共 N 次心动」统计（2026-11-15 用户调整）。
- 头像用 `getAvatarUrl` 缩略图；点击卡片用 `UserDetailCardModal`（默认 `userApi.getUserDetail`）。
- 消息提示用 `useAppNotification`；列表上方工具条，**刷新按钮放右侧**。

## 方案选择

- **选定**：新增独立组件 `OnsiteLoveRankTab.tsx`，弹窗 TAB 数组末尾加一项，按现有 cp/routine 的懒挂载模式（`tabKey === 'loveRank' ? … : null`）。改动最小、与现有 TAB 一致。
- 备选一（表格 StandardTable 分页）：不采用——展示是版式化卡片列表，非管理型表格，且配对量小。
- 备选二（仅互相心动过滤）：不采用——与历史大屏一致展示全部心动配对（用户已确认）。

## 交互与版式（已确认）

- 工具条：左侧「按现场心动次数倒序」说明，右侧「刷新」按钮（`ReloadOutlined`）。
- 每行：左侧**男**嘉宾卡片（头像 + 现场序号 + 昵称，可点击），中间「第 N 名」+ 红心行 + 蓝心行，右侧**女**嘉宾卡片（同左）。
- **2026-11-15 用户调整**：男女对调（左男右女）；去掉「男方发起/女方发起」文字（仅保留红/蓝心形图标）；去掉「共 N 次心动」统计行。
- 空状态：「暂无现场心动配对」。
